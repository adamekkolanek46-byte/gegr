# The Character Creator

This directory contains a static build of **The Character Creator**
by Frédéric Guimont, taken from upstream commit
`f335d02e371dee75ba7afa306b3ef6ca46c9b44a`:

- Website: https://charactercreator.org/
- Source: https://github.com/ubik23/charactercreator

The only local change removes the upstream website's analytics scripts for
visitor privacy; the character editor and artwork are otherwise unchanged.
